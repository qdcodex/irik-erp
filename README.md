# Irik College ERP System

A modern, web-based Enterprise Resource Planning system for colleges, built with Next.js and TypeScript.

## Quick Start

```bash
# Install dependencies
npm install

# Run development server
npm run dev
```

Visit `http://localhost:3000` to see the application.

## Modules Included

1. **Dashboard** - Overview with key metrics
2. **Students** - Student information management
3. **Courses** - Course catalog and details
4. **Enrollments** - Student course enrollment tracking
5. **Fee Management** - Payment tracking and collection
6. **Faculty** - Faculty information and assignments
7. **Admissions** - Application processing and tracking

## Tech Stack

- Next.js 14
- React 18
- TypeScript
- Tailwind CSS

## Features

- **Student Management**: Add, view, and manage student records
- **Course Management**: Create and organize courses by semester
- **Enrollment Tracking**: Track student enrollments and grades
- **Fee Management**: Monitor student fees and payment status
- **Faculty Directory**: Maintain faculty information
- **Admissions Processing**: Process and track applications
